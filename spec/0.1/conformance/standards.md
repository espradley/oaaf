# Adopted-standards inventory

are **not** upgraded during O6A; this records what is pinned today and what happens if
upstream evolves. Where a source is an Internet-Draft, the behavior it underpins is isolated
as experimental (see [classification.md](classification.md)).

## Reconciliation notes

- **Do not upgrade during O6A.** AAT `-01` expires 17 Dec 2026; a `-02` (or a WG adoption)
  will be a deliberate new profile version via RFC, not a silent bump. The conformance spec
  version (`0.1`) and the AAT revision move together only by decision.
- Two behaviors rest on **Internet-Drafts** (Token Status List, WIMSE identifier). Both are
  confined to **optional profiles** and marked experimental, so neither can silently become a
  mandatory v1 requirement. This is the guardrail the O6A brief requires.
- Everything in the **Core** class rests on **published standards** (AuthZEN, JCS, JWK
  Thumbprint, JWT/JOSE, RFC 7800) plus **AAT `-01`**, the single pinned draft the entire
  project is built on. Core does not depend on any _other_ draft.
