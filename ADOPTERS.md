# Adopters

This file lists organizations and individuals who have **voluntarily identified themselves**
as evaluating or using OAAF.

## This list is empty by design

No entries have been independently verified yet. That is the honest current state, and it is
recorded rather than hidden.

Two rules keep this list meaningful:

1. **Self-identification only.** Names are added because an adopter chose to be listed — by
   filing the [adopter declaration](https://github.com/espradley/oaaf/issues/new?template=adopter.md).
   Maintainers do not add names on anyone's behalf, and neither does any automated tool.
2. **Independent verification.** An entry is added only after the declaration is
   independently verified (a public integration, a reachable contact, or a maintainer
   confirming the claim). Aspirational, friendly, or unverifiable names do not belong here.

A short, verified list is worth more than a long, decorative one — especially for anyone
assessing whether OAAF has real, independent uptake.

## Declare adoption

Open the [adopter template](https://github.com/espradley/oaaf/issues/new?template=adopter.md)
and tell us what you are building. Listing here is entirely optional; adopting OAAF requires
no announcement and no permission. How adoption is otherwise observed — without any telemetry
in the SDK — is described in [docs/adoption-signals.md](docs/adoption-signals.md).
